# Omar Elgedawy · Portfolio

Personal site styled as a Codeforces round: the landing page is the problem list, and each section (About, Education, Experience, Projects, Upsolving, Teaching, Videos, Standings, Skills, Contact) opens as its own problem statement.

Live: https://omar123098.github.io/portfolio/

- Single `index.html`, no build step. Served by GitHub Pages from `master`.
- `resume/Omar Elgedawy.pdf` is the resume linked from the top bar. Replace this file to update it.
- `og-image.png` is the link-preview image; `favicon.svg` is the tab icon.
- Keyboard: `A` to `J` opens a problem, arrow keys move between problems, `Esc` returns to the list.
